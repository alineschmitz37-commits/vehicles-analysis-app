# Análise de Dados de Veículos Usados

Este projeto é uma aplicação web interativa desenvolvida em Python para análise exploratória de um conjunto de dados de vendas de carros nos Estados Unidos.

# Funcionalidades da Aplicação
 Visualização de Histograma: Exibe a distribuição da quilometragem dos veículos.
 Gráfico de Dispersão: Mostra a relação entre a quilometragem e o preço dos veículos.
 Filtros Interativos: Permite alternar visualizações utilizando checkboxes/botões interativos construídos com Streamlit.

# Tecnologias Utilizadas
 Python
 Pandas
 Plotly Express
 Streamlit
 Render (Hospedagem)
